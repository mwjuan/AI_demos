# 六阶段 AI 开发课程地图

本文是课程顺序、阶段依赖和闯关标准的唯一权威来源。课程按能力成熟度推进，不承诺固定周数；建议每课安排约 4 小时，并在上一阶段通过后再开始下一阶段。

## 总路线

| 阶段 | 要解决的问题 | 主线项目里程碑 | 进入条件 |
|---|---|---|---|
| [S01 入门](../curriculum/stage-01/README.md) | 能否安全、独立地从 Python 调用模型并完成聊天应用？ | 命令行与 Streamlit 聊天机器人 | 无编程基础也可开始 |
| [S02 应用开发](../curriculum/stage-02/README.md) | 能否把模型能力做成稳定、可校验的 Web 应用？ | 流式聊天与学习卡片生成器 | S01-GATE |
| [S03 核心技术](../curriculum/stage-03/README.md) | 能否理解并训练基础模型、解释 Embedding 和 Transformer？ | 文本分类与检索基线 | S02-GATE |
| [S04 智能体开发](../curriculum/stage-04/README.md) | 能否构建有证据、可调用工具、可评估的 Agent？ | 企业级 RAG 知识库智能体 | S03-GATE |
| [S05 定制开发](../curriculum/stage-05/README.md) | 能否微调、部署并治理多智能体系统？ | 垂直模型与多智能体助手 | S04-GATE；GPU 实验可使用云算力 |
| [S06 算法进阶](../curriculum/stage-06/README.md) | 能否处理图像、跨模态检索和生成任务？ | 多模态知识助手 | S05-GATE；具备训练与部署经验 |

## 阶段依赖

```text
S01 Python 与模型调用
  └─ S02 工程化应用开发
       └─ S03 模型核心技术
            └─ S04 RAG 与智能体
                 └─ S05 模型定制与多智能体
                      └─ S06 算法与多模态进阶
```

依赖表示推荐学习顺序，不表示所有技术只能出现一次。重要能力会螺旋式复现：例如评估在 S02 建立接口测试，在 S03 学习模型指标，在 S04 扩展为 RAG 与 Agent 评估，在 S05 加入线上观测和降级。

## 统一课次与验收规则

- 课次编号统一为 `Sxx-Lxx`，阶段验收为 `Sxx-GATE`。
- 每课写明前置知识、可观察目标、必做实验、检查方式、反思问题和完成证据。
- 每课通过标准固定为“能运行、能解释、能修改”；只看完材料不计为完成。
- 每个阶段必须提交主线项目增量、一个没有逐行答案的独立挑战，以及一次口头数据流解释。
- 阶段验收失败时，只补对应能力，不重复已经验证通过的内容。

## 阶段成果概览

### S01：AI 大模型开发入门

掌握 Python 基础、模型 API、Ollama、提示词、上下文和密钥安全。完成命令行与 Streamlit 聊天机器人，能够处理认证、超时、限流和模型错误。

### S02：大模型应用开发

掌握 Python 面向对象与进阶语法、NumPy、Pandas、MySQL、FastAPI、流式响应、结构化输出，以及 Coze/Dify 原型验证。把聊天机器人升级为可取消、可校验、可持久化的 Web 应用。

### S03：大模型核心开发技术

掌握机器学习建模流程、PyTorch、神经网络、NLP、Embedding、Transformer、BERT 和 GPT。建立文本分类与语义检索基线，用固定指标解释方案优劣。

### S04：大模型智能体开发

掌握 LangChain、LangGraph、向量数据库、混合检索、重排、引用、工具调用、MCP、Human-in-the-Loop 和可观测性。交付可以拒绝无依据回答、恢复失败并接受固定评估的知识库智能体。

### S05：大模型定制开发

掌握 Hugging Face、迁移学习、SFT、LoRA、P-Tuning、QLoRA、量化、DeepSpeed、vLLM、A2A 与生产治理。交付可部署的垂直模型和带权限、降级、监控的多智能体助手。

### S06：大模型算法进阶

掌握数据结构与算法、CV 分类/检测/分割、扩散模型、ViT、CLIP、VLM、跨模态检索，以及强化学习与 RLHF 基础。将主线系统升级为支持图片理解、图文检索和生成的多模态知识助手。

## 不在当前骨架中展开

独立 Java 技术栈、物联网业务课和传统微服务专项不属于这条 Python AI 主线。相关课程中的工程经验会在 API 设计、持久化、容器化、权限、监控和部署环节吸收，但不单独设置 Java 或物联网阶段。
