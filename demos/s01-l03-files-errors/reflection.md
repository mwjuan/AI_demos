## 能解释

1. `message_utils.py` 和 `conversation_store.py` 为什么要分开？前者负责验证和清洗消息，后者负责读写文件，让每个模块只承担一种主要职责。
2. `path` 参数和函数返回值分别是什么？`path` 指定文件位置；`load_messages` 返回给用户的是消息列表，用户不需要知道文件内部的 `version`。
3. `json.dump` 与 `json.load` 的方向有什么不同？`dump` 把 Python 数据写入 JSON 文件，`load` 从 JSON 文件读取成 Python 数据。
4. 为什么保存前还要调用 `normalize_message`？确保写入文件的消息结构和类型正确，并跳过空消息。
5. 为什么文件不存在可以返回空列表，而 JSON 损坏必须报错？文件不存在可能只是首次运行；文件损坏表示已有数据无法可信读取，不能伪装成没有历史记录。
