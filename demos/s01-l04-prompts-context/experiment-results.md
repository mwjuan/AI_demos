# S01-L04 实验结果

实验日期：2026-09-20

## 单变量提示词实验

固定用户问题：

```text
解释大语言模型处理文本时的 Token，不要讨论登录认证 Token。
```

### concise

`system`：使用简洁的中文回答，不超过 80 个汉字。

模型输出（59 个字符）：

```text
Token 是文本分词后的最小处理单元，可以是字、词或子词。模型将文本切分为 Token 序列，再转换为向量进行计算。
```

### analogy

`system`：使用生活化比喻，向小学生解释；不超过 80 个汉字。

模型输出（59 个字符）：

```text
就像把句子拆成乐高小块——“我爱学习”变成【我】【爱】【学】【习】4个Token，模型靠这些小块理解、拼接和生成文字！
```

结论：两组都满足长度限制并正确聚焦大模型 Token；`analogy` 组明显使用生活化比喻。第一次实验中的“解释 Token”存在歧义，两组都误解成登录认证 Token；明确领域后消除了歧义。
