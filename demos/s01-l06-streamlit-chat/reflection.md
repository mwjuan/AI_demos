## 已理解与纠正的概念

- 学习者能解释：模型使用请求携带的历史回答，不会自动永久记住姓名。
- 学习者起初混淆响应校验与请求校验，复习后能指出空回答由
  `extract_assistant_reply()` 拒绝。
- 学习者起初认为脚本重新执行就应创建空列表；随后复习了字典键存在判断，
  以及 `st.session_state` 在当前会话多次执行间保留历史的作用。
- 清空聊天只清除 `messages`，不等于清空全部状态；`model` 与 `timeout` 保留。
- 解析 JSON 后，还必须验证结束原因与回答内容；保存的是提取后的
  assistant 消息，不是整个 JSON 响应。
- 请求失败进入 `except`，不执行 `else` 的回答保存；错误文本不作为模型回答
  加入后续上下文。请求前保存的用户问题仍保留。
- 学习者能解释：提高超时只增加允许等待的时间，不提高生成速度。
