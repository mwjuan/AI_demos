## 能解释

1. `list` 和 `dict` 在对话数据中分别负责什么？
list是任意类型的集合，可以有顺序的保存多条消息；dict是字典，使用键值对保存一条消息
2. 为什么要先验证类型，再调用 `strip()`？
只有str类型可以调用strip()，否则会报错
3. `continue` 对本次循环和后续循环分别有什么影响？
跳出本轮剩余代码，不影响后续循环
4. 为什么函数返回一个新字典，而不是直接修改传入的消息？
会有引用问题，字典是可变对象，直接修改会影响调用方持有的原字典。
5. 空消息与类型错误为什么要采用不同处理方式？
本质不同，一个是输入为空但内容仍然合法，一个是类型错误违反数据约定
