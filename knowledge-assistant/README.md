# 个人知识库助手

这是贯穿六阶段的主线项目。每个阶段只增加已经学会并能解释的能力，不提前复制后续阶段答案。

## 演进路线

| 阶段 | 主线增量 | 明确不提前实现 |
|---|---|---|
| S01 入门 | 命令行聊天、Streamlit、多提供商配置、本地会话 | 检索、工具、数据库服务 |
| S02 应用 | FastAPI、SSE、停止生成、schema 校验、MySQL 会话 | 向量数据库、Agent |
| S03 核心技术 | 文本清洗、切分、Embedding 检索、分类与指标基线 | LangChain/LangGraph 自动编排 |
| S04 智能体 | 混合检索、重排、引用、拒答、工具、MCP、检查点、评估 | 模型微调、多智能体生产治理 |
| S05 定制 | 垂直模型、统一推理服务、多智能体、权限、审计、降级 | 多模态视觉能力 |
| S06 进阶 | 图片理解、OCR/VLM、图文索引、跨模态检索、受控生成 | 未经评估的研究型功能 |

## 最终能力

完成路线后，本地版应支持：

1. 导入 Markdown、TXT、PDF、办公文档和图片。
2. 查看切分、索引、检索和重排的原始证据。
3. 基于证据回答并给出可定位引用；证据不足时明确说明。
4. 根据资料生成并校验测验题，在用户确认后保存学习记录。
5. 通过职责清晰的多个 Agent 完成检索、测验和学习规划。
6. 使用固定评估集比较检索、生成、工具和模型方案。
7. 对关键调用记录 Trace、成本、延迟、权限和审计信息。
8. 理解图片、执行图文检索，并在受控条件下生成视觉内容。

## 工程边界

- S01-S04 优先本地单用户体验，S05 才引入多用户/租户权限和生产治理。
- 数据库、模型和向量存储通过接口隔离，允许从本地实现迁移到生产实现。
- 任何写入、外部操作或高风险工具必须有明确权限；学习记录写入默认要求用户确认。
- 每次新增能力必须同时补充成功、拒绝、失败和恢复路径的测试。
