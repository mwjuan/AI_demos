# S01 AI 大模型开发入门

## 阶段定位

从零建立 Python 与大模型调用能力。完成后，学习者可以安全地调用云端或本地模型，观察请求与响应，并独立完成一个可交互的聊天机器人。

## 前置知识

- 会使用终端打开目录和运行命令即可。
- 不要求已有 Python、机器学习或 Web 开发经验。

## 课程列表

| 编号 | 主题 | 可观察目标 | 必做实验与完成证据 |
|---|---|---|---|
| S01-L01 | 从 Python 发出第一次模型请求 | 调用模型、读取文本/请求 ID/token，并给出可行动错误 | 保留现有三组提示词实验、测试结果和反思；实现位于[现有课程](../../demos/week-01-first-api/README.md) |
| [S01-L02](../../demos/s01-l02-python-data/README.md) | Python 数据、控制流与容器 | 使用变量、判断、循环、字符串、列表和字典处理对话数据 | 编写对话统计器；用测试覆盖空消息和异常输入 |
| S01-L03 | 函数、模块、文件与异常 | 拆分函数和模块，读写文件并区分可恢复/不可恢复错误 | 保存并恢复本地对话；提交一次故障定位记录 |
| S01-L04 | 提示词、上下文与结构化消息 | 解释 system/user/assistant 消息、随机性、上下文边界和幻觉 | 单变量提示词实验；生成可解析 JSON 并记录失败样本 |
| S01-L05 | Ollama 与本地模型 | 安装并调用本地模型，比较云端与本地的质量、速度和隐私 | 相同测试集双模型对比；保存耗时、token/资源和结论 |
| S01-L06 | Streamlit 聊天机器人 | 构建多轮聊天 UI，安全读取配置并展示错误 | 演示聊天、清空历史和错误提示；不得向浏览器暴露密钥 |

## 必做实验

- 对同一问题只改变一个提示变量，比较至少三组结果。
- 分别制造缺失密钥、错误模型名和超时，记录现象、猜测、证据和修复。
- 用同一测试问题对比云端模型与 Ollama 本地模型。

## 主线项目增量

初始化个人知识库助手：先提供命令行聊天，再增加 Streamlit 界面和本地会话记录。此阶段不实现检索或工具调用。

## 闯关标准

`S01-GATE` 必须同时满足：

- S01-L01 的自动测试与进度检查通过。
- 能在没有示例代码的情况下完成一次模型调用，并正确处理三类失败。
- 能画出“用户输入 → Python → 模型 API → 响应 → 界面”的数据流。
- 完成一个变式挑战：为聊天机器人增加可切换模型与安全的参数配置。
- 用自己的话解释 token、上下文、随机性、幻觉和密钥为何不能放在前端。
