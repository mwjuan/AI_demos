# S03 大模型核心开发技术

## 阶段定位

理解模型为什么能工作、如何训练和如何评价。学习者需要从调用现成 API，前进到能够训练基础模型、解释 Embedding 与 Transformer，并用数据比较方案。

## 前置知识

- 已通过 `S02-GATE`。
- 能处理表格数据、编写测试并构建 Python Web API。

## 课程列表

| 编号 | 主题 | 可观察目标 | 必做实验与完成证据 |
|---|---|---|---|
| S03-L01 | 机器学习全流程与特征工程 | 区分特征/标签/数据集，避免数据泄漏并建立基线 | 完成分类任务的数据切分、预处理、训练与报告 |
| S03-L02 | 模型评估与经典算法 | 解释过拟合、交叉验证、混淆矩阵和主要指标 | 比较线性模型、树模型和集成模型；说明指标取舍 |
| S03-L03 | PyTorch、张量与自动微分 | 使用张量和自动微分实现训练循环 | 从零训练 MLP；保存损失曲线、模型和复现实验配置 |
| S03-L04 | CNN、RNN 与训练调优 | 解释卷积、序列状态、损失函数、优化器和正则化 | 完成小型图像分类或文本序列任务并诊断过拟合 |
| S03-L05 | NLP、分词与 Embedding | 实现文本预处理、向量化和余弦相似度检索 | 为个人笔记建立 Embedding 检索基线并展示命中片段 |
| S03-L06 | Transformer 与注意力 | 解释自注意力、位置编码、Encoder/Decoder 和 mask | 手算小型注意力案例并使用 PyTorch 验证结果 |
| S03-L07 | BERT、GPT 与迁移学习基础 | 区分编码器/解码器模型及其任务，调用预训练模型 | 完成文本分类或语义相似度实验并提交模型卡 |

## 必做实验

- 故意制造数据泄漏和类别不平衡，观察指标为何会误导。
- 修改学习率、批大小和正则化，只改变一个变量并记录训练曲线。
- 比较词袋、稠密 Embedding 和预训练模型在同一检索集上的结果。

## 主线项目增量

为知识库助手加入文本清洗、切分和 Embedding 检索基线；同时建立可重复运行的文本分类实验和指标报告，为后续 RAG 提供检索与意图识别基础。

## 闯关标准

`S03-GATE` 必须同时满足：

- 能从原始数据完成训练、验证、测试和模型保存，不混用数据集。
- 能解释 Transformer 中一次 token 表示更新的主要步骤。
- 提交固定检索测试集，对至少三种表示方法给出指标、耗时和结论。
- 完成独立挑战：在未提供答案的数据集上改进一个基线，并证明提升来自有效实验而非数据泄漏。
