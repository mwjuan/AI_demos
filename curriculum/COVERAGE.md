# 学习路线覆盖矩阵

本矩阵把原学习路线中的学习内容、能力产出和岗位方向映射到新的六阶段课程，避免重排时遗漏主题。重复内容只设置一个主讲阶段，后续阶段通过项目再次使用。

| 路线阶段 | 原路线重点 | 新课程主讲位置 | 可验证能力产出 | 对应岗位方向 |
|---|---|---|---|---|
| 1 AI 大模型开发入门 | Python 基础、数据处理、Ollama、私有模型、ChatBot | S01-L01 至 S01-L06 | 独立调用模型 API；完成聊天机器人；解释 token、上下文、幻觉与密钥安全 | 初级 AI 开发工程师 |
| 2 大模型应用开发 | Python 进阶、NumPy/Pandas、Prompt、Coze/Dify | S02-L01 至 S02-L07 | 快速构建并交付经过 schema 校验的智能应用 | AI 应用开发、低代码智能体开发 |
| 3 大模型核心开发技术 | 机器学习、深度学习、PyTorch、Transformer、NLP、BERT/GPT | S03-L01 至 S03-L07 | 完成模型训练、评估和语义检索基线；读懂核心论文结构 | 机器学习、深度学习工程师 |
| 4 大模型智能体开发 | LangChain/LangGraph、向量数据库、RAG、Agent | S04-L01 至 S04-L08 | 构建可引用、可评估、可观测、可恢复的企业知识库智能体 | Agent、RAG、智能体全栈工程师 |
| 5 大模型定制开发 | Transformer、迁移学习、微调、部署、多智能体协作 | S05-L01 至 S05-L07 | 微调并部署垂直模型；治理带权限、降级和监控的多智能体系统 | 大模型开发、算法、训练工程师 |
| 6 大模型算法进阶 | CV、多模态、Stable Diffusion、图文检索、专题算法 | S06-L01 至 S06-L07 | 开发图片理解、检测/分割、图文检索与生成应用 | CV、图像处理、多模态工程师 |

| 能力 | 首次建立 | 后续深化 |
|---|---|---|
| 配置与密钥安全 | S01-L01 | S02 API 配置、S05 权限与生产密钥治理 |
| 提示词与结构化输出 | S01-L04 | S02-L05、S04 Agent 输出协议 |
| 数据处理 | S01 Python 容器 | S02 NumPy/Pandas/MySQL、S03 特征工程 |
| 评估 | S01 提示词对比实验 | S03 模型指标、S04 RAG/Agent 评估、S05 线上指标 |
| 部署 | S01 Ollama 本地运行 | S02 Web API、S04 容器化、S05 vLLM 与生产治理 |
| 安全与人工确认 | S01 密钥安全 | S04 提示注入与 Human-in-the-Loop、S05 权限审计 |
| 可观测性 | S01 请求 ID 与 token | S04 Trace、S05 成本/性能/降级监控 |

## 内容取舍

- 保留 Python AI 开发全链路以及课程大纲中的模型、RAG、Agent、微调、多模态和工程化内容。
- 合并多份大纲中重复的 Prompt、LangChain、RAG、Agent 和 Transformer 内容。
- 不设置独立 Java、物联网和传统微服务课程；可迁移的工程思想进入对应 Python 项目课。
- Coze/Dify 用于快速验证需求，不替代 Python 代码实现和底层原理学习。
