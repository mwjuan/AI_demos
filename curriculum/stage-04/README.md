# S04 大模型智能体开发

## 阶段定位

构建有证据、会调用工具、能够暂停确认并可被评估的智能体。重点解决幻觉、黑盒执行、失败恢复和资料不足时的可靠行为。

## 前置知识

- 已通过 `S03-GATE`。
- 能解释 Embedding、相似度检索、结构化输出和基本模型指标。

## 课程列表

| 编号 | 主题 | 可观察目标 | 必做实验与完成证据 |
|---|---|---|---|
| S04-L01 | LangChain 组件与 LCEL | 组合模型、Prompt、解析器、Retriever 和 Runnable | 将现有调用封装为可测试链，并保留提供商切换能力 |
| S04-L02 | 文档处理与向量数据库 | 实现加载、切分、Embedding、索引和元数据过滤 | 导入 Markdown/TXT；引用能定位到真实原文 |
| S04-L03 | 混合检索、重排与查询改写 | 比较稠密/稀疏检索、融合和 reranker | 用固定集测 Precision、Recall、MRR 与延迟 |
| S04-L04 | RAG 生成、引用与拒答 | 只依据证据回答，资料不足时明确拒答 | 注入无答案问题和冲突资料；验证引用与声明一致 |
| S04-L05 | 工具调用、ReAct 与安全边界 | 定义、校验和执行工具，限制循环并恢复失败 | 实现搜索笔记、生成测验、保存记录三个工具；写入前确认 |

| S04-L07 | MCP 与外部能力接入 | 实现最小 MCP Server/Client 并约束工具权限 | 将一个业务能力标准化接入；记录输入输出与错误协议 |

## 必做实验

- 对不同切分、Embedding、检索和重排组合运行同一评估集。
- 在笔记中放入提示注入文本，验证它不能覆盖系统规则或触发未授权写入。
- 模拟工具超时、无效参数和部分失败，验证最大步数、重试与恢复路径。
- 从 Trace 定位一次错误检索、一次 Prompt 问题和一次异常 token 消耗。

## 主线项目增量

把知识库助手升级为企业级 RAG Agent：支持资料导入、混合检索、可定位引用、无依据拒答、工具调用、人工确认、检查点恢复、固定评估和链路追踪。

## 闯关标准

`S04-GATE` 必须同时满足：

- 评估集覆盖可回答、不可回答、引用、提示注入、工具选择和失败恢复。
- 能展示一次完整 Trace，并解释每个节点的输入、输出、耗时和 token。
- 未经确认不能写入学习记录；工具调用有 schema、权限和最大步数。
- 完成独立挑战：新增一个工具和一个工作流分支，并为成功、拒绝与失败路径补齐测试。
