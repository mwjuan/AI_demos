# S06 大模型算法进阶

## 阶段定位

扩展到图像、跨模态检索和生成任务，并补齐算法分析与强化学习视角。最终系统能够理解和检索图文资料，而不是只处理纯文本。

## 前置知识

- 已通过 `S05-GATE`。
- 能训练、评估、部署模型，并理解 Transformer 与生产推理链路。

## 课程列表

| 编号 | 主题 | 可观察目标 | 必做实验与完成证据 |
|---|---|---|---|
| S06-L01 | 数据结构、复杂度与常用算法 | 分析时间/空间复杂度并选择合适结构和算法 | 手写链表、树遍历和排序；用基准证明一次优化 |
| S06-L02 | 图像处理与 CNN/ResNet | 完成图像预处理、增强、分类和迁移学习 | 训练图像分类器；提交混淆矩阵和错误样本分析 |

## 必做实验

- 用数据规模、输入尺寸和模型结构解释一次训练或推理性能瓶颈。
- 对分类、检测、分割分别保存典型错误样本并提出可验证改进。
- 对跨模态检索分别测量文本找图、图片找文和最终回答质量。
- 对生成内容记录可复现参数，并验证不安全输入的处理边界。

## 主线项目增量

将知识库助手升级为多模态系统：导入图片与图文文档，进行 OCR/VLM 理解、跨模态检索、可定位引用和受控图片生成；沿用前一阶段的权限、评估、观测和降级能力。

## 闯关标准

`S06-GATE` 必须同时满足：

- 系统能导入并检索图文资料，回答中引用可定位到文本片段或图片区域。
- 分类、检测/分割、跨模态检索和生成至少各有一组可复现实验记录。
- 能解释从输入图片到向量、检索、模型推理和结果展示的完整数据流。
- 完成独立挑战：实现一个未提供答案的多模态能力，并用冻结测试集证明其有效。

## 完成路线

通过 `S06-GATE` 即完成六阶段主路线。后续可根据目标选择模型研究、AI 平台、行业解决方案或大规模生产系统专项。
