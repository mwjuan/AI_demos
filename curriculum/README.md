这里维护所有阶段的课程目录。根目录的[课程地图](../notes/ROADMAP.md)决定学习顺序；各阶段 README 决定课次、实验、项目增量和闯关标准。

|---|---:|---|---|
| S01 AI 大模型开发入门 | 6 课 + 闯关 | [stage-01](./stage-01/README.md) | 命令行与 Streamlit 聊天机器人 |

| S06 大模型算法进阶 | 7 课 + 闯关 | [stage-06](./stage-06/README.md) | 多模态知识助手 |

## 课程编写模板

后续编写单课讲义时统一包含以下部分：

1. 课程编号与名称。
2. 前置知识。
3. 可观察的学习目标。
4. 概念、核心编码、实验排错和复盘安排。
5. 必做实验与变式挑战。
6. 自动测试或人工检查方法。
7. 反思问题与完成证据。

完整主题覆盖情况见[路线覆盖矩阵](./COVERAGE.md)。
